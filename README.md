# MEHAK, pure oil attar

A demo website for an invented attar brand, designed and built by Abdul Wasay Shaikh.

- Plain HTML, CSS and vanilla JavaScript, with GSAP, ScrollTrigger and Lenis for the scroll work.
- The hero is a scroll-scrubbed film: a light copy plays first, the sharp one swaps in when it lands.
- All product photos and the hero video are AI-generated.

The brand, prices, address and customer quotes are invented for the demo. The order and newsletter forms send nothing.
